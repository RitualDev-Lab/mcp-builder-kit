Pre-Flight Defense Against AI Agent Supply-Chain Exploits

AI agents execute tools with autonomous context. A single unvalidated path or unescaped shell template string can lead to remote code execution or credential leakage. AgentShield inspects your code before you ever connect to Claude or Cursor:

✔ Shannon Entropy Scanning

Detects high-entropy keys (>4.4 bits/char) even if disguised or un-patterned.

✔ Shell Chaining & Traversal Blocks

Flags command separators (;&|$) and URL-encoded traversals (%2e%2e).

✔ Zero-Leak Parameter Sanitizer

Generates drop-in TypeScript and Python runtime middleware to sanitize every parameter.

✔ Strict Zero-Leak Score Gate

Requires 0 critical, 0 high, and 0 medium findings to achieve verified status.
