# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The RitualDev Lab team takes the security of agentic toolchains and Model Context Protocol servers seriously. If you discover a vulnerability in `mcp-builder-kit` (such as command injection in generators, insecure scaffolding defaults, or HMAC signature validation bypasses):

1. **Do not open a public issue.**
2. Send a detailed report to **contact@ritualdev.in** (subject: `[SECURITY] mcp-builder-kit Vulnerability Report`).
3. Include reproduction steps, sample templates/code, and the impacted environment.

We commit to acknowledging vulnerability reports within 48 hours and collaborating on a patch before public disclosure.
