# Security Policy & Vulnerability Disclosure

RitualDev Lab takes the security of `@ritualdev-lab/mcp-builder-kit` and generated Model Context Protocol (MCP) servers seriously.

## Supported Versions

| Version | Supported | Minimum Runtime | Response Target |
| :--- | :---: | :---: | :---: |
| **1.2.x** | Active | Node.js >= 20.0.0 | Critical & High: < 24 Hours |
| < 1.2.0 | End-of-Life | Node.js >= 18.0.0 | Upgrade to latest 1.2.x |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for undisclosed security vulnerabilities.

- **GitHub Private Security Advisory (Preferred)**: [Report a Security Advisory](https://github.com/RitualDev-Lab/mcp-builder-kit/security/advisories/new)
- **Email**: `security@ritualdev.in` with subject `[SECURITY VULNERABILITY] @ritualdev-lab/mcp-builder-kit`

Please include a minimal reproduction or Proof-of-Concept (PoC), affected version, and impact summary (e.g., ReDoS, code generation injection, transport/auth flaw).

## Safe Harbor

RitualDev Lab will not pursue legal action against researchers acting in good faith who follow coordinated vulnerability disclosure and avoid accessing or exfiltrating third-party data.

## Compliance & Control Alignment

- **Status**: SOC 2 Type II & ISO 27001 Control-Mapped Architecture (**Self-Attested Readiness; Formal Independent Audit Planned**).
- **Trust & Control Mapping Portal**: [https://ritualdev.in/trust](https://ritualdev.in/trust)
